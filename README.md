# СЛОЙ — сайт-презентация изделий на 3D-принтере

Одностраничный сайт на Flask: каталог изделий, поиск, фильтр по тегам,
подборки «Популярное» и «Новинки», подробные карточки и форма заявки.

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

Откройте в браузере: <http://127.0.0.1:5000>

Если `flask` ещё не установлен, достаточно команды:

```bash
pip install flask
```

## Структура проекта

```text
.
├── app.py                  # Flask: загрузка каталога и приём заявок
├── content.json            # ВСЕ карточки товаров и контакты
├── requirements.txt
├── templates/
│   └── index.html          # разметка страницы
└── static/
    ├── style.css           # оформление и адаптивность
    ├── script.js           # поиск, фильтры, модальные окна
    ├── favicon.svg
    └── images/             # иллюстрации изделий
```

## Как добавить новую карточку

1. Откройте `content.json`.
2. Скопируйте любой объект из массива `products` (от `{` до `}`).
3. Вставьте его в конец массива через запятую.
4. Измените поля. Обязательные:

| Поле | Что это | Пример |
| --- | --- | --- |
| `id` | Уникальный адрес карточки, латиницей | `"wall-clock"` |
| `title` | Название | `"Часы «Круг»"` |
| `short` | Короткое описание для карточки | `"Настенные часы..."` |
| `description` | Полное описание для окна | `"Печатаем корпус..."` |
| `category` | Раздел | `"Декор"` |
| `tags` | Теги для фильтра | `["Декор", "Дом"]` |
| `price` | Цена числом, без пробелов | `1590` |
| `image` | Путь к картинке от папки `static` | `"images/wall-clock.jpg"` |
| `url` | Ссылка на изделие / страницу заказа | `"https://vk.com/..."` |
| `rating` | Оценка | `4.8` |
| `reviews` | Количество отзывов | `12` |
| `added` | Дата в формате ГГГГ-ММ-ДД | `"2026-11-01"` |

Необязательные: `old_price` (старая цена), `badge` (свой текст бейджа),
`features` (список преимуществ), `specs` (характеристики), `accent` (цвет
подсветки карточки).

5. Чтобы карточка попала в подборку, поставьте `"popular": true` или
   `"new": true`.
6. Если добавляете своё фото, положите его в `static/images/` и укажите
   путь `"images/имя-файла.jpg"` (или `.png`, `.webp`, `.svg`).

Перезапускать сервер после правки `content.json` не нужно: обновите страницу.

## Как изменить контакты

Контакты, телефон, ссылки на Telegram и ВКонтакте находятся в начале
`content.json` в блоке `"site"`. Они автоматически подставляются в шапку,
подвал и кнопки.

## Где смотреть заявки

После отправки формы заявка сохраняется в `orders.json` в папке проекта.
Этот файл создаётся автоматически. Его не нужно открывать в браузере —
это обычный JSON-список. Файл добавлен в `.gitignore`, чтобы персональные
данные не попали в репозиторий.

Важно: форма демонстрационная. Для реального сайта подключите почту,
Telegram-бота или CRM — достаточно отправлять данные из функции
`create_order()` в `app.py`.

## Что можно быстро настроить

- **Цвета и шрифты** — переменные в начале `static/style.css` (`:root`).
- **Название бренда** — поле `brand` в `content.json` и логотип в
  `templates/index.html`.
- **Тексты на первом экране** — секция `<section class="hero">` в
  `templates/index.html`.
- **Вопросы FAQ** — блок `faq__list` в `templates/index.html`.
- **Порядок карточек в каталоге** — порядок объектов в `products`.

## Публикация

Для демонстрации подойдёт любой хостинг с Python. В продакшене запускайте
Flask не встроенным сервером (`debug=True`), а через WSGI-сервер, например
`waitress` или `gunicorn`, и выключите отладочный режим.
